1. Go to Spotify Developer Dashboard and create an app.
2. In settings, set the Redirect URI exactly to:
https://prog-rank.vercel.app/
3. Copy your Client ID and paste it below.
Note: Only works for Spotify Premium members for full features (metadata fetches still work for free users).
